Plataforma de Gestión Académica

Sistema web full-stack para la gestión integral de carreras terciarias. Administra alumnos, docentes, títulos, planes de estudio con correlatividades, cursadas, asistencias, certificados y mesas de examen. Backend con Node.js + Express + Prisma + PostgreSQL, frontend con React + Vite + Tailwind. 4 roles con permisos diferenciados (Admin, Secretaría, Profesor, Alumno) y dashboard con métricas institucionales exportables a PDF y CSV.

Node.js Express Prisma PostgreSQL React Vite Tailwind Docker
